Project Description

This software design document provides a brief description of Fire Simulator which is a VR-based simulation for Robi Axiata Ltd. VR i.e., Virtual Reality is a computer-generated environment with scenes and objects that appear to be real, making the user feel they are immersed in their surroundings. The goal of this software is to reduce the time and cost limitations of setting up a physical firefighting simulation for the users.



High Level Requirements

  1. Robi Axiata Full Buiding as a level
  2. Creating three types of Fire - Electric, Kitchen, General
  3. Extinguishing Mechanism using tools - Hose pipe, ABC and CO2 Extinguishers
  4. Gammify the whole simulation
  5. Admin panel for monitoring the performance of the users with api connectivity

  • Oculus Integration
